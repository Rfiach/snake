# Snake

Klassisches Snake im Browser – eine einzige Datei, keine Installation.

## Starten
`index.html` im Browser öffnen.

## Steuerung
- **Pfeiltasten / WASD:** Richtung
- **Leertaste / P:** Pause
- **Enter:** Start / Neustart
- Touch: Steuerkreuz oder Wischen

## Optionen
- **Wrap-around:** durch die Wand auf der Gegenseite wieder heraus
- **Hindernisse:** feste Blöcke auf dem Feld
- **Spezialfutter:** goldener Stern, +50 Punkte, mit Zeitlimit

Normales Futter bringt 10 Punkte; mit jedem Futter wird die Schlange schneller. Highscore wird pro Optionskombination gespeichert.
